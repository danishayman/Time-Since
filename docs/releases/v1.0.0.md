The first release of Time Since: track how long it has been since, or how long there is until, the moments that matter to you.

## Highlights
- Live timers that count up from a past date or down to a future one.
- Stop, resume or restart at any time. Every restart is logged with how long that run lasted.
- Show each timer in the units you choose: years, months, weeks, days and the clock.
- File timers under coloured categories and filter the list by them.
- Four home-screen widget styles, including one with a restart button.
- Light and dark themes, plus JSON backup export and import.
- No accounts, no tracking: everything stays on your phone.

## Install
1. Download **`time-since-1.0.0.apk`** below on your Android phone.
2. Open it, and allow installs from your browser or file manager if asked.
3. To add a widget, long-press your home screen and choose **Widgets → Time Since**.

Android only for now; an iPhone version is planned.
